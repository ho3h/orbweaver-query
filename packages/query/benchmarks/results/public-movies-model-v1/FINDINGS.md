# Backend correctness on a second public graph family

Exported the pinned public movies fixture through the read-only Neo4j adapter:
171 nodes, 253 edges, six ordered relation types and maximum neighbor degree 13.
This exercises a different graph/schema from WN18RR. It uses fixed random numeric
test coefficients, with no claim about useful movie predictions or trained-model
transfer. The fixture script is downloaded separately and not redistributed here.

The frozen input-only source selection takes 16 random nodes plus four highest
degree nodes (18 distinct nodes after overlap). An independent oracle enumerates
individual walks rather than merging path-prefix states. It matches all candidate
sets and all 3,894 scores across six relations; maximum absolute difference is
4.44e-16, below the predeclared 1e-12 tolerance.

Four complete request workloads—distinct128, clustered192, interleaved192 and
hubs16—match bitwise across independent, consecutive, grouped and bounded LRU
execution. Interleaved grouping and LRU perform 32 expansions versus 192 for the
consecutive cache. These are correctness/work-counter checks, not isolated timing
benchmarks and not a cross-domain predictive-quality result.

The verifier reloads the saved graph/model, re-enumerates all oracle walks and
repeats every strategy comparison and output digest. Both execution and replay
pass. Source, manifest, metrics and replay receipt are preserved; numeric graph
and test-model artifacts are regenerated by the command below.

```sh
python packages/query/tools/public_movies_check.py freeze movies-check
python movies-check/source/public_movies_check.py execute movies-check \
  --neo4j-home /path/to/neo4j --java /path/to/java
python movies-check/source/public_movies_check.py verify movies-check
```

The same public fixture revision/checksum is used in the Text2Cypher corpus
campaign. No existing user database or remote demo endpoint is contacted.
