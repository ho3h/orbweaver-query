# Changelog

## 1.0.0.dev1 (public preview preparation)

- Public movie walkthrough with local HTML evidence, independent native Cypher checks,
  runnable CSV integration, and a guide for bringing your own graph.
- Mac-only release audit, installed-wheel performance protocol and scoped source archive.
- Exact bound-target preparation, conventional structural models and shared
  feature preparation across compatible inference operators.
- Inspectable multi-model plans, explicit score caching and selective-first
  execution, with graph/model identities and exact row/provenance contracts.
- Typed graph expansion between inference stages, optional expansion and
  dependency-safe movement of score filters before candidate generation.
- Bounded intermediate rows, per-stage traversal/inference profiles and atomic
  cache writes for each root window. Neo4j's read-only adapter accepts pipelines.
- Request-scoped reuse of exact two-hop walk state across scoring batches,
  explicit numeric retention budgets and vector traversal over packed evidence.
- Bounded preparation for the union of stage targets, shared across compatible
  models and sliced for scoring batches; explicit domain and work accounting.
- Stable deduplication of validated feature-group bindings within scoring batches,
  with exact restoration of row bags, payloads, nulls and later operator results.
- Select relevant edges once per node and hop before processing typed walk
  prefixes. A fresh-prefix benchmark ablation separates retained intermediate
  state from completion-kernel improvements on unchanged query inputs.
- Retained strong-control comparisons, including unfavorable fresh-query results.
  The [1.0 acceptance gates](benchmarks/v1/ACCEPTANCE.md) remain open; this is not
  a public release or a claim of parity with Quail or GDS.

## 0.1.0 (unreleased)

- Independent NumPy runtime with immutable, versioned graph/model artifacts.
- Source-aware bounded grouping with exact row-order and duplicate restoration.
- Scored candidate bindings with explicit null/unsupported states, filtering,
  projection and graph/model provenance.
- Parameterized read-only Neo4j integration and explicit evidence projection.
- Reproducible WN18RR path-model training, trained demo, model card and notices.
- Independent path enumeration checks, real corpus conformance, isolated runtime
  measurements and full Cypher workflow measurements with a bounded LRU control.

The [current release audit](RELEASE_AUDIT.md) distinguishes Mac preview validation
from the historical 0.1 checks and the still-open competitive 1.0 gates. No PyPI release or public repository publication has been performed.
